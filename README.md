
## Running Locally

```bash
cd Backend
dotnet run -c Debug
```
Will run both the backend and frontend at the same time. Go to `http://localhost:6768` to see it in action.

To run just the backend, run it in `Release` mode. 

To run just the frontend, do `npm run dev` in the `Frontend` folder.
